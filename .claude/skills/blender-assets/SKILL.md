# Blender assets

All textures and models are generated by scripts in `tools/blender/` using Blender as a
Python module (`pip install bpy==5.2.2`, Python 3.13). The outputs are committed.

| Script | Output | Notes |
|---|---|---|
| `make_textures.py [names]` | `assets/textures/*_albedo.png`, `*_normal.png` | Tileable PBR (4D noise on a torus). |
| `make_rocks.py` | `assets/models/rocks/*.glb` | Mesa with tunnels, arches, hoodoos, boulders. |
| `make_choppa.py [--preview DIR [views]]` | `assets/models/choppa/choppa.glb` | The helicopter. |
| `make_airframes.py [gunship] [heavy] [striker] [mule] [--preview DIR]` | `assets/models/choppa/gunship.glb`, `heavy.glb`, `striker.glb`, `mule.glb` | The other classes; reuse make_choppa's helpers and markers (plus `pod_l/r` for rockets). The coaxial striker has `rotor` and `rotor_upper` and only an empty `tail_rotor`. |
| `make_cockpit.py [classes] [--preview DIR [classes]]` | `assets/models/choppa/cockpit_<class>.glb` | One interior per class, origin = the pilot's eye (the class's `eye` empty: keep `EYES` in step with make_airframes.py). Parts library: `cockpit_parts.py`. Objects `shell`, `frame`, `stick`, `collective`, and `mount_*` empties the game fills (see `Cockpit`); a mount the model lacks is skipped. Previews render five views from the eye. |
| `make_props.py [--preview DIR [names]]` | `assets/models/props/props.glb` | Map props: station pad, pylon, camp buildings, trestle, harbour containers, gantry crane, warehouse, ship hulk, radio mast. New paint names need a case in `Props._apply_materials`. |
| `make_trees.py [--preview DIR]` | `assets/models/trees/trees.glb`, `assets/textures/needles_albedo.png` | Pines. |
| `choppa_shared.py` | (module) | Canopy geometry used by both choppa and cockpit. |

Run with `python tools/blender/<script>.py` (Windows: `python`, Linux: `python3`).

## Workflow

1. Change the script, never the .glb by hand.
2. Iterate with `--preview DIR`: Cycles renders (views for the choppa: front, chase,
   side, top, engine, nose) in seconds, much faster than game screenshots. Read the PNGs.
3. Export (run without `--preview`), re-import in Godot (`--headless --path . --import`),
   run the tests, then check in the game with the `screenshot` skill.

## Conventions

- Coordinates: Blender +Y is the nose, +Z up. glTF export uses `export_yup=True`, so
  Blender (x, y, z) becomes Godot (x, z, -y): the nose points to Godot -Z (forward).
  An empty's local +Z (Blender) arrives as local +Y in Godot.
- Import `bpy` before `bmesh`. `bpy.ops.object.transform_apply` defaults to
  `location=True`: rotate geometry with `mesh.transform(matrix)` instead of ops when the
  object sits away from the origin.
- Materials are placeholders named by role; the game swaps in its own by name
  (`ChoppaModel.part_materials`): paint (hull shader with seams, rivets, wear), metal,
  dark, glass, brass, rubber, exhaust, lamp, hazard, decal, marking_red, light_red,
  light_green; trees use bark and needles. A new name needs a case there.
- The game reads empties from the choppa: `eye`, `muzzle_l/r`, `exhaust_l/r`,
  `crack_0..7`, and the objects `rotor` / `tail_rotor` that spin. Cockpit empties
  `mount_*` hold live instruments (`scripts/cockpit.gd`).
- Keep the canopy frame in `choppa_shared.py` so the cockpit view matches the outside.
  If the eye moves, the gameplay muzzle offsets in `choppa.gd` `_shoot` may need to move.
- Budgets: choppa ~60k triangles, cockpit ~15k, pine ~7k. Godot builds LODs on import.
- New textures: their `.import` file must have `compress/mode=2`, `mipmaps/generate=true`,
  `detect_3d/compress_to=0`, and `compress/normal_map=1` for normal maps. Godot creates
  the file on import with other defaults; fix it, then re-import.
